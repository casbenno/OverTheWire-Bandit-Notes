# OverTheWire Bandit Notes

Personal walkthrough notes for the [Bandit wargame](https://overthewire.org/wargames/bandit/) on OverTheWire — a beginner-friendly game for learning basic Linux command-line and security concepts through SSH.

## What's inside

`overthewire_org_annotated.md` — level-by-level notes covering:
- The level goal
- The exact commands used to solve it
- The terminal output
- A short **Theory** section explaining what each command/flag does and why it works

## Why

Solving each level is easy to forget once the password's found. These notes exist so the *reasoning* behind each command sticks — not just the answer.

## Progress

Currently covers Bandit Level 0 → Level 12.

## Note on credentials

Per [OverTheWire's rules for educators/content-creators](https://overthewire.org/rules/), no level passwords are published in these notes — only the commands and reasoning used to find them. Run each command yourself after connecting.
